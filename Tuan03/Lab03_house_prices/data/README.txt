Dữ liệu gốc của cuộc thi Kaggle "House Prices - Advanced Regression Techniques".
Tải tại: https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data
(cần đăng nhập Kaggle và bấm "Join Competition" trước).

Đặt vào thư mục này:
  train.csv              1460 căn, 79 đặc trưng + Id + SalePrice
  test.csv               1459 căn, 79 đặc trưng + Id (không có SalePrice)
  data_description.txt   mô tả ý nghĩa từng cột và từng giá trị (ĐỌC KỸ phần NA)
